# A guide to Island Defense

Island Defense is a custom map for Warcraft III. Some concepts of the Warcraft III engine can be esoteric, this guide tries to explain all of them, and other strategy in the game.


# How to contribute

Any high effort contribution is welcome. 

### 1. Clone the repo

```git clone https://github.com/islanddefense/guide
cd guide 
```

### 2. Install mkdocs + theme + extensions

Probably use a virtual environment.


```pip install mkdocs
pip install mkdocs-dracula-theme
pip install pymdown-extensions
```

### 3. Test changes

```mkdocs serve
```

Open `http://127.0.0.1:8000`in a browser to view changes.

You can also DM me with any contribution on discord `azizxoxo` if you prefer and I'll add it. I reserve the right to reject or modify any contribution.
